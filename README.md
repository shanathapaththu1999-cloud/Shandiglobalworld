# SHANDI GLOBAL WORLD — starter website

Mobile-first static website for GitHub Pages.

## Files
- `index.html` — homepage
- `style.css` — responsive styling
- `app.js` — service cards, language toggle and VISH demo
- `assets/favicon.svg` — favicon
- `pages/privacy.html` and `pages/terms.html` — initial policy drafts

## Publish with GitHub Pages
Repository Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/(root)` → Save.

## Important limitations
This is a frontend starter, not the complete production platform. No live database, admin authentication, shared gallery uploads, public comments/reactions, AI API, phone calling, enquiry backend or payment system is connected. Do not collect sensitive customer data until secure services and policies are configured. Never put API keys in these public files.
